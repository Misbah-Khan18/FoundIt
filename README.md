FoundIt 🔎
Lost it? Found it? Let FoundIt connect the two.

FoundIt is a smart campus Lost & Found platform built for MIT World Peace University (MIT-WPU) — designed to make reporting, discovering, claiming, and verifying lost belongings simpler and more organized.

Instead of searching through messages, notice boards, or scattered campus groups, FoundIt brings the entire process into one place.

✦ What makes it different?

FoundIt doesn't just collect lost and found reports.

It helps connect them.

Its Smart Matching Engine compares lost and found reports using description, image, location, and date/time to surface potential matches for administrators to review.

From there, admins can verify claims, confirm matches, and keep the process moving — while students receive updates through in-app notifications and email.

🧠 Smart Matching

FoundIt's matching engine evaluates:

Description 45% · Image 35% · Location 10% · Date 10%

The result is a Match Confidence Score that helps administrators prioritize potential matches.

The system suggests. The administrator decides.

A match is never treated as confirmed simply because the score is high.

🔄 The idea

Report → Match → Verify → Claim → Reconnect

A simple flow for a problem that usually isn't.
